A tool that audits a BigQuery project and flags where it is wasting money, starting with tables that are missing partitioning and clustering.

  • It reads only INFORMATION_SCHEMA metadata. It never touches the data itself.
  • It builds on the approach I used to cut query costs by 15% at Jobint.

Data Engineering

Fakecommerce Pipeline

End-to-end pipeline orchestrated with Airflow on Docker. It goes from a public API to PostgreSQL, then to a dimensional model in dbt, with Power BI on top.

  • 11 dbt models split by business domain, and around 36 tests as the last task of the DAG. If a test fails, bad data does not reach the dashboard.
  • I started it on DuckDB and migrated it to PostgreSQL after lock issues with concurrent writes.
