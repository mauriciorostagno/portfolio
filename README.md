# Portfolio

Personal portfolio of Mauricio Rostagno, Analytics Engineer.

Live site: https://mauriciorostagno.github.io/portfolio/

## Structure

```
index.html              Single page: hero, about, experience, projects, contact
assets/css/style.css    Design tokens, components and responsive rules
assets/js/main.js       Navbar, tabs, project filters, copy email, typing effect
assets/img/             Project images, favicon and link preview image
assets/files/           Resume (PDF)
```

Plain HTML, CSS and JavaScript. No build step and no dependencies, served by GitHub Pages.

## Run locally

Open `index.html` in a browser.
